# Imagecutter
세로 이미지를 분할하여 가로로 다시 붙이는 프로그램

## 기능
- **이미지 분할**: 원하는 위치에서 잘라 다시 이어 붙이기
  - 가로선으로 잘라 옆으로 붙이기 / 세로선으로 잘라 위아래로 쌓기
  - N칸으로 똑같이 나누기
  - 제목을 쓰면 조각을 `제목_01.png`, `제목_02.png` … 개별 파일로 저장, 또는 합본 1장 저장
- **배경 제거**: 이미지를 넣으면 배경을 지워 투명 PNG로 저장
  - AI 자동: 브라우저 안에서 AI 모델로 처리 (처음 한 번 모델 다운로드, 인터넷 필요, 이미지는 서버로 전송되지 않음)
  - 단색 배경: 흰 배경 같은 단색 배경을 색 기준으로 제거 (오프라인 가능, 클릭으로 배경색 지정)
